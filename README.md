# DuskBloom Screen 🌙🌸

DuskBloom Screen is the Windows screen-filter component of the DuskBloom suite.
It provides comfortable full-screen tinting and brightness controls designed to reduce harsh screen appearance.

## Current release

**DuskBloom Screen v3.4.4**

This repository contains the source and automated Windows build configuration. End users should install DuskBloom Screen through DuskBloom Center or download the compiled Windows release — they do not need Python.

## Build locally

Run `BUILD_DUSKBLOOM_SCREEN.bat` on a Windows development PC with Python installed.
The compiled app is written to `dist\\DuskBloomScreen.exe`.

## DuskBloom Center

`manifest.json` exposes the component metadata DuskBloom Center can use for version detection, executable name, and startup behavior. Release downloads can be connected to GitHub Releases as the suite updater is finalized.
