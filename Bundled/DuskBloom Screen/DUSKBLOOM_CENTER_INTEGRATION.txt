DUSKBLOOM SCREEN ↔ DUSKBLOOM CENTER
======================================

Native DuskBloom bridge:
%APPDATA%\DuskBloom\DuskBloomScreen\

state.json    = live DuskBloom Screen state
manifest.json = supported commands and version
command.json  = commands sent by DuskBloom Center

DuskBloom Center can control:
- screen filter/color
- intensity
- mode
- presets
- enabled state
- pause
- match all monitors
- darken side monitors
- individual monitor color/intensity/on-off
- DuskBloom Screen menu theme

The app retains compatibility with the old working settings so the rename
does not reset the user's monitor setup.
