DuskBloom Center v1.0.2

Fixes:
- Correctly locates bundled apps in PyInstaller 6's _internal folder.
- Correctly locates update_catalog.json in frozen builds.
- Detects apps already installed under %LOCALAPPDATA%\DuskBloom\Apps.
- DuskBloom Screen Open finds the built Screen executable in its permanent install folder.
- DuskBloom Sonar Open uses its installed launcher even though Sonar is currently script-based.
- DuskBloom Web is recognized when its extension files are already installed locally; Open launches its Web manager.
- Build script no longer reports failure just because bundled data lives under _internal.
